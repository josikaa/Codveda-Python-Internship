# Task 1: Simple Calculator

## Description

The Simple Calculator is a command-line Python application that
performs four basic arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

The program takes two numbers from the user and allows the user
to select an arithmetic operation. It then performs the selected
operation and displays the result.

The program also includes error handling for division by zero
and invalid operation choices.

## Objectives

The main objectives of this task are:

- To create separate functions for arithmetic operations.
- To accept numerical input from the user.
- To allow the user to select an operation.
- To perform the selected arithmetic calculation.
- To handle division by zero appropriately.
- To display the result clearly.

## Technologies Used

- Python 3
- Built-in Python functions
- Command Line Interface (CLI)

## Concepts Used

- Functions
- User input
- Conditional statements
- Floating-point numbers
- Return statements
- Basic error handling

## How the Program Works

1. The program displays the calculator title.
2. The user enters the first number.
3. The user enters the second number.
4. The program displays four available operations.
5. The user selects an operation from 1 to 4.
6. The corresponding function is called.
7. The result is displayed.
8. If division by zero is attempted, an appropriate error
   message is displayed.
